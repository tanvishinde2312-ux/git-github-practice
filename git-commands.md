# Git Commands Cheat Sheet

This file contains commonly used Git commands with simple explanations.

---

## Check Git Version

```bash
git --version
```

Displays the installed Git version.

---

## Clone a Repository

```bash
git clone <repository-url>
```

Copies a remote repository to your computer.

---

## Check Repository Status

```bash
git status
```

Shows the current status of your working directory.

---

## Add Files

```bash
git add .
```

Stages all modified files.

---

## Commit Changes

```bash
git commit -m "Initial commit"
```

Saves staged changes with a commit message.

---

## Push Changes

```bash
git push origin main
```

Uploads commits to GitHub.

---

## Pull Changes

```bash
git pull origin main
```

Downloads the latest changes from GitHub.

---

## View Commit History

```bash
git log
```

Displays previous commits.

---

## Create a New Branch

```bash
git branch feature-branch
```

Creates a new branch.

---

## Switch Branch

```bash
git checkout feature-branch
```

Moves to another branch.

---

## Merge a Branch

```bash
git merge feature-branch
```

Combines another branch into the current branch.

---

## Delete a Branch

```bash
git branch -d feature-branch
```

Deletes a local branch after merging.

---

## Useful Commands

```bash
git init
git remote -v
git fetch
git diff
git restore .
```

---

## Learning Outcome

After learning these commands, I can:

- Create repositories
- Track changes
- Commit updates
- Push projects to GitHub
- Work with branches
- Collaborate using Git
